# Decisions

This folder stores architecture and platform decisions for the infrastructure handbook.

---

## Use this folder for

- Cloud landing-zone decisions.
- Identity and access design decisions.
- Networking and segmentation decisions.
- Tooling and delivery workflow decisions.
- Exceptions that need a durable record.

---

## Decision record pattern

Keep each decision short and explicit:

1. Context.
2. Decision.
3. Alternatives considered.
4. Consequences.
