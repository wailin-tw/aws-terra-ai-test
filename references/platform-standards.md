# Platform Standards

These standards are the default baseline for infrastructure work across AWS, Azure, GCP, and OCI.

---

## Standards

- Use least privilege for identities and service roles.
- Keep environments isolated and clearly named.
- Encrypt data in transit and at rest.
- Store secrets in managed secret systems only.
- Require code review for infrastructure changes.
- Prefer reusable modules over copy-paste definitions.
- Tag resources for owner, environment, cost center, and purpose.
- Review logs and alerts as part of normal operations.
